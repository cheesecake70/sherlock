05 / Policy

The role contract

This JSON is the agent's whole job description: allowed tools, restricted paths, approved destinations and the dollar limit. Edit it, save, and the next run uses it.

How it is used

Changes apply to the next run. A run already in progress keeps the contract it started with. Weights must add up to 1. Bands set when a score becomes STEP-UP or BLOCK.

07 / Live agent

Checking status…
What is real: checks, scores, ledger and eval numbers are real code. Scripted scenarios script the agent's behaviour. Attribution is a word-overlap heuristic.

What is real, what is scripted

  • REALEvery verdict, score and meter. They come from the same engine code in all views.
  • REALThe hash-chained audit ledger, including tamper detection.
  • REALEvidence numbers: the engine run over a labelled case suite, just now.
  • REALLive agent tab (when enabled): a real model picks the calls.
  • SCRIPTEDIn the demo scenarios, the agent's tool calls and the vendor files are written in advance.
  • ILLUSTRATIVEThe learning-based detector in the cold-start race is a model of the approach, not a measured product.
  • HEURISTICAttribution is a word-overlap measure. It is not a causal-attribution method and can be fooled by paraphrase. That is why the contract and tripwire exist.
